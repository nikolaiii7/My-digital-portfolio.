My Computing Journey

The Evolution of Computers

One topic from IT111 that interested me is the evolution of computers. I find it interesting to see how computers developed from earlier, larger machines into smaller and more capable devices that are part of everyday life.

One important development is the invention of the transistor. Transistors helped make computers smaller, more reliable, and more practical. This development contributed to the progress of modern computing technology.

When I create and view this portfolio on a computer, the computer system follows the basic Input, Processing, Storage, and Output cycle.

Part Example in My Portfolio
Input Typing HTML and CSS code using the keyboard.
Processing The computer processes the code and the browser interprets it.
Storage The HTML, CSS, and image files are saved in the portfolio folder.
Output The browser displays the finished portfolio on the screen.

Module 3: Connected World

When someone visits a website, the device connects to a network and uses the Internet to communicate with other computers. A web browser requests website information, and an IP address helps identify a device or destination on the network. These connected systems allow people to access websites and exchange information.
